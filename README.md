# java-calculator-precourse

## 구현할 기능 목록

1. 입력값 처리
  - [x] 입력된 문자열이 빈 문자열인지 판별
  - [x] 입력된 문자열이 커스텀 구분자가 있는지 판별
  - [x] 입력된 문자열이 비어있지 않고 시작 부분이 올바르다면 문자열을 넘겨줌
2. 구분자 처리
  - [x] 커스텀 구분자의 유무를 반영하여 구분자 배열에 구분자들을 추가
3. 실제 덧셈 부분 추출
  - [x] 입력된 문자열에서 실제로 덧셈이 실행될 부분 추출
4. 토큰 스캔
  - [x] 추출된 덧셈이 실행될 부분을 순회하며 올바른 입력인지 확인하고 이를 배열로 저장
5. 덧셈 수행
  - [x] overflow 예외를 고려하면서 덧셈 수행
  - [x] 덧셈 수행 결과물 불러오기
6. Application
  - [x] 앞서 구현된 클래스 및 메서드를 이용해 프로그램 실행

## 프로그래밍 요구 사항
- [x] JDK 21 버전에서 실행 가능 여부 확인
- [x] 프로그램 실행의 시작점은 Application의 main()   
- [x] build.gradle 파일 변경 불가   
- [x] 제공된 라이브러리 이외의 외부 라이브러리 사용 불가   
- [x] 프로그램 종료 시 System.exit() 호출하지 않음   
- [x] 프로그램 요구사항에서 명시되지 않은 파일, 패키지 등의 이름 변경 및 이동 불가   
- [ ] 자바 코드 컨벤션 준수
